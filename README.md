# Kushagra Dhawan

I make tools for people who make things.

Since 2021, I have led product and design at [Womp 3D](https://womp.com), a 3D modeling tool in the browser. I design the product, I write its frontend, and I built [Womp's Design System](https://github.com/KushagraDhawan1997/kookie-ui), which the product runs on.

That design system is where [Kookie](https://kookie.design) started. Kookie is named after my dog, and it is where I build tools of my own.

- [Kookie UI](https://ui.kookie.design), a design system on Base UI
- [Kookie Flow](https://flow.kookie.design), a node graph library that draws everything in WebGL
- [Kookie Studio](https://github.com/KushagraDhawan1997/kookie-flow/tree/main/apps/studio), an app for AI images and video, built on Kookie Flow
