## What I'm Building

### [Kookie UI](https://hellokookie.com) — Design System

A system to build consistent and scalable user interfaces. An open-source fork of [Radix Themes](https://github.com/radix-ui/themes) with a fresh visual style and practical foundations. Tokens, primitives, patterns, accessibility, motion, theming hooks, keyboard paths, and predictable behavior across states. Kookie UI powers all of Womp's production interface.

→ [Website](https://hellokookie.com) · [npm](https://www.npmjs.com/package/@kushagradhawan/kookie-ui) · [GitHub](https://github.com/KushagraDhawan1997/kookie-ui) · [Article: Why Designers Should Own the Experience in Production](https://kushagradhawan.com/articles/designers-own-the-experience-in-production)

### [Kookie Flow](https://github.com/KushagraDhawan1997/kookie-flow) — WebGL Node Graph Engine

A WebGL-native node graph library for React. React Flow's ergonomics, GPU-rendered for performance at scale. Nodes are instanced meshes, edges are GPU line segments, one camera uniform update, 1-2 draw calls, done. 50,000+ nodes at 60fps. Built with MSDF text rendering, mipmap-based LOD for images, and viewport frustum culling.

→ [GitHub](https://github.com/KushagraDhawan1997/kookie-flow) · [Article: About Kookie Flow](https://kushagradhawan.com/kookie-flow)

### [Kookie Blocks](https://kookieblocks.com) — Component Library

Higher-level implementation of Kookie UI focused on reusable blocks for app interfaces and marketing pages. Includes StreamingMarkdown (performance-optimized markdown renderer for AI streaming), Chatbar, Shell (declarative layout engine), and more.

→ [Website](https://kookieblocks.com) · [npm](https://www.npmjs.com/package/@kushagradhawan/kookie-blocks) · [GitHub](https://github.com/KushagraDhawan1997/kookie-blocks)

### [Kookie AI](https://kushagradhawan.com/kookie-ai) — Spatial AI Workspace

A desktop-first, web-based product where conversations are nodes in a branching graph, not linear scrolls. Branch anywhere, create alternate paths, compare outputs across models, and treat artifacts as first-class nodes. Currently in development.

→ [About Kookie AI](https://kushagradhawan.com/articles/about-kookie-ai)

## About My Work at Womp

I joined Womp in 2021 as the founding designer and evolved into a role that spans product, design, and engineering. I scaled down from 3 designers to just myself while improving conversion metrics (join-to-trial from 3% to 5%, maintaining 40% trial-to-paid). I write production React code, lead product decisions, and conduct user research calls weekly.

I built KookieUI because I needed design decisions to live in code, not in Figma files. The frontend imports components from KookieUI, I define their appearance, tokens, and behavior. When anything needs an update, I adjust KookieUI and publish a new version. The app adopts the new standard automatically with a version bump.
