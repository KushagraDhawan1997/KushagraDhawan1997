# Kushagra Dhawan

I make tools for people who make things.

I lead product and design at [Womp 3D](https://womp.com), a 3D modeling tool in the browser. I design the product, write its frontend, and maintain [Womp's Design System](https://github.com/KushagraDhawan1997/kookie-ui), which every screen in Womp is built from.

[Kookie](https://kookie.design) is where I build my own tools. It is named after my dog.

- [Kookie UI](https://ui.kookie.design), a design system that applies what research has measured, such as tap size and contrast, and decides everything else once
- [Kookie Flow](https://flow.kookie.design), a node editor for React that stays smooth with thousands of nodes
- [Kookie Studio](https://github.com/KushagraDhawan1997/kookie-flow/tree/main/apps/studio), a node canvas for AI images and video, built on Kookie Flow
