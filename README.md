## What I'm Building

### [Kookie UI](https://hellokookie.com) — Design System

The design system behind Womp's production interface. It started as a fork of [Radix Themes](https://github.com/radix-ui/themes) and is becoming its own system: it is leaving the fork and moving onto [Base UI](https://base-ui.com), one component at a time. It is a work in progress, and its docs say where it does not yet follow its own principles.

→ [Website](https://hellokookie.com) · [npm](https://www.npmjs.com/package/@kushagradhawan/kookie-ui) · [GitHub](https://github.com/KushagraDhawan1997/kookie-ui) · [Article: Why Designers Should Own the Experience in Production](https://kushagradhawan.com/articles/designers-own-the-experience-in-production)

### [Kookie UI v2](https://github.com/KushagraDhawan1997/kookie-ui-v2) — Design System, Rebuilt

A ground-up rebuild, and the experimental one. v1 is the simpler system, built for a product in daily use. v2 tests how far modern design can go: Base UI primitives, colour generated in OKLCH, token-only styling, and a CSS budget that CI enforces. It has no `variant` prop. `tone` says what a thing means and `emphasis` says how loud it is. Both versions share the same principles. Not released yet.

→ [GitHub](https://github.com/KushagraDhawan1997/kookie-ui-v2)

### [Kookie Flow](https://github.com/KushagraDhawan1997/kookie-flow) — WebGL Node Graph Engine

A React library for node-graph editors: shader graphs, AI pipelines and whiteboards. It draws nodes, edges, text, widgets, images, video and 3D models in WebGL, so a board of thousands of nodes pans and zooms without React re-rendering. Active again, and now built on Kookie UI v2.

Alongside it I'm building **Studio**, a node-based app for AI image and video generation built on Kookie Flow. You ask an agent, and it answers with a workflow instead of a single result: it asks what you need, drafts cheap low-fidelity directions, lets you pick, then makes the final with the best model. Pricing is pass-through model cost plus a stated fee, with no subscription. In development.

→ [GitHub](https://github.com/KushagraDhawan1997/kookie-flow) · [Article: About Kookie Flow](https://kushagradhawan.com/kookie-flow)

### [Kookie AI](https://kushagradhawan.com/kookie-ai) — Spatial AI Workspace

A desktop-first, web-based product where conversations are nodes in a branching graph, not linear scrolls. Branch anywhere, create alternate paths, compare outputs across models, and treat artifacts as first-class nodes. On pause for now.

→ [About Kookie AI](https://kushagradhawan.com/articles/about-kookie-ai)

## About My Work at Womp

I joined Womp in 2021 as the founding designer and evolved into a role that spans product, design, and engineering. I scaled down from 3 designers to just myself while improving conversion metrics (join-to-trial from 3% to 5%, maintaining 40% trial-to-paid). I write production React code, lead product decisions, and conduct user research calls weekly.

I built KookieUI because I needed design decisions to live in code, not in Figma files. The frontend imports components from KookieUI, I define their appearance, tokens, and behavior. When anything needs an update, I adjust KookieUI and publish a new version. The app adopts the new standard automatically with a version bump.
